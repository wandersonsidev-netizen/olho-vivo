# 📰 Olho Vivo

**Olho Vivo** é um site de notícias desenvolvido como projeto acadêmico durante o semestre letivo do curso de Sistemas de Informação.

O projeto tem como objetivo apresentar conteúdos informativos por meio de uma página organizada, com navegação por categorias e elementos visuais.

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Font Awesome

## 📌 Funcionalidades e recursos

- Menu de navegação por categorias.
- Carrossel de imagens.
- Organização de conteúdos em cartões.
- Layout responsivo utilizando Bootstrap.
- Ícones disponibilizados pelo Font Awesome.

## 🚀 Acesso ao projeto

O site está publicado por meio do GitHub Pages e pode ser acessado pelo link:

## ⚙️ Como executar localmente

1. Faça o download ou clone este repositório.
2. Extraia os arquivos, caso tenha baixado o projeto compactado.
3. Abra o arquivo `index.html` em um navegador.

Para clonar o projeto:

```bash
git clone https://github.com/wandersonsidev-netizen/olho-vivo.git
```
